# Kryptix Assistant – AI Chatbot

An intelligent conversational chatbot powered by **Google Gemini**, built using **Python, FastAPI, and Streamlit**.

Kryptix Assistant provides contextual responses, remembers previous messages within a conversation, and offers a simple interactive chat interface.

## Features

- **Gemini API Integration:** Uses Google's Gemini LLM for generating intelligent responses.
- **Multi-Turn Conversations:** Maintains conversation history using unique conversation IDs.
- **Context Management:** Sends the latest 10 messages to the model to maintain relevant context.
- **Custom System Prompt:** Defines the chatbot's identity, personality, and purpose.
- **FastAPI Backend:** Provides a REST API for chatbot communication.
- **Streamlit Frontend:** Provides an interactive chat interface.
- **Error Handling:** Handles API failures, connection errors, and request timeouts.
- **Environment Variables:** Protects API credentials using a `.env` file.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd openai-chatbot
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure the Gemini API Key

Create a `.env` file in the project root directory.

Add your Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Get an API key from [Google AI Studio](https://aistudio.google.com/apikey).

**Important:** Never upload your actual `.env` file or API key to GitHub.

### 5. Start the Backend Server

Open a terminal and run:

```bash
python -m uvicorn backend.main:app --reload
```

Backend URL:

```text
http://127.0.0.1:8000
```

Interactive API documentation:

```text
http://127.0.0.1:8000/docs
```

### 6. Start the Frontend

Open another terminal, activate the virtual environment, and run:

```bash
streamlit run frontend/app.py
```

Frontend URL:

```text
http://localhost:8501
```

## API Documentation

### POST /chat

Accepts a user message and returns a response generated by Gemini.

**Request Body:**

```json
{
  "message": "Hello! Introduce yourself.",
  "conversation_id": null
}
```

**Response:**

```json
{
  "conversation_id": "generated-conversation-id",
  "reply": "Hello! I am Kryptix Assistant..."
}
```

For follow-up messages, send the same `conversation_id` to continue the existing conversation.

### GET /

Checks whether the backend API is running.

## Conversation and Context Management

Each conversation is assigned a unique ID.

- New conversations receive a new ID.
- Messages are stored in conversation history.
- The latest 10 messages are passed to Gemini as context.
- Previous messages help the chatbot generate context-aware responses.

Conversation history is maintained in backend memory and is reset when the backend process restarts.
